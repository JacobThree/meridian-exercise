# MS-142 — Show check-in streak on the home screen

**Vendor:** Northwind Digital  **Status:** Ready for acceptance  **Branch:** `vendor/streak-counter`

Participants see "N of 10" on the home screen: how many days in a row they have checked in.

## Acceptance criteria

1. The streak is the number of consecutive days with a check-in. If the participant has
   checked in **today**, the streak ends today. If not yet, it ends yesterday. Today's check-in
   must be counted.
2. "Today" means the participant's **local date** (their saved timezone), not the server's date
   and not UTC.
3. A participant can see **only their own** streak.
4. If the lookup fails, the API must return an error so the app shows its "try again" state.
   It must never show "0" for a failed lookup.
5. Unit tests cover: checked in today, not yet checked in today, a gap in the streak, and the
   timezone boundary (an evening check-in in a US timezone, which is already "tomorrow" in UTC).
6. No participant identifiers (email, name, date of birth) are written to logs.
7. CI stays green and the coverage gate is unchanged.
