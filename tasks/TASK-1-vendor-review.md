# Task 1 — Review a vendor delivery (about 20 min)

Northwind Digital, the outside vendor, says card **MS-142** is done and wants you to accept it
so they can invoice. You own the decision.

```bash
git diff main..vendor/streak-counter
```

Read `cards/MS-142.md` for the acceptance criteria. You do not have to run the code; you may.

## Write up, in `answers/task1.md`

1. **Decision:** accept / reject / accept with conditions. One sentence of reasoning.
2. **Findings, most serious first.** For each: file and line, what is wrong, why it matters, and
   what you would ask the vendor to do.
3. **What you'd leave alone:** anything in the diff you looked at and decided is fine or not worth
   raising.
4. The 3 to 5 sentence message you would send the vendor.

Think aloud while you work. We care about what you notice and how you rank it more than how many
items you list.
